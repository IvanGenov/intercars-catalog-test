# Интеркарс — GATE-02, безопасна синхронизация (етап за преглед)

## Цел
Google Sheets → съществуващ публичен Apps Script API → GitHub Actions проверка → нова версия на GitHub Pages.

- Старият работещ сайт **остава непроменен**, докато не одобрим PR и не направим реален тест.
- GitHub Actions не се опитва да зарежда API-то в браузъра на посетителя — това е причината за досегашния проблем.
- 30-минутно планирано обновяване и ръчен старт от Actions. GitHub може да забави или пропусне планиран старт; не е гаранция за точно време.
- Няма нужда от GitHub PAT. Използва се краткоживеещият токен за Pages с `pages: write`, `id-token: write`, но **няма** `contents: write`.
- Грешен HTTP, невярна JSONP форма, празни/извънсхемни данни, невалидни Drive снимки → целият workflow спира преди Deploy. Последният успешен сайт остава достъпен.
- За всяко успешно изпълнение се публикува нов Pages артефакт; няма директни записи в Google таблицата или в GitHub хранилището.
- Четат се **само** публичните полета. Не се публикуват продажби, приходи, списъци с администратори, вътрешни бележки или токени.

## Нужно преди реално активиране
1. Проверка на PR и тестовете.
2. При одобрение: GitHub → Settings → Pages → Source → **GitHub Actions** (сега е Deploy from a branch).
3. Merge на workflow в `main` след одобрение.
4. GitHub Actions → `Intercars public catalog sync and deploy` → Run workflow.
5. Успешен workflow + тест на мобилен Chrome **без Инкогнито** + сравнение на промяна в Google Sheets (първо на тестови данни).
6. Ако Google API връща HTML/redirect към login в Actions, workflow ще спре. Не заобикаляме авторизацията; диагностицираме го и не излагаме лични данни.

## Важно за обновяването
При този вариант GitHub Pages се обслужва от публикувания GitHub Actions артефакт. 
Не трябва да се оставя Pages Source на `Deploy from a branch`, понеже автоматичен commit с `GITHUB_TOKEN` не задейства Pages build според документацията.

## Отворени въпроси
Визуалният тест в обикновен Chrome (без Инкогнито) остава отделна проверка, защото досегашното отваряне през ChatGPT може да използва вътрешен браузър. Реалното HTTPS зареждане на GitHub Actions още не е проверено.
