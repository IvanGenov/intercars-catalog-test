# Intercars — GATE-02 public catalog (TEST ONLY)

Тестова публична витрина за автомобили и части.

- [Каталог — GitHub Pages](https://ivangenov.github.io/intercars-catalog-test/)
- Източник на браузърната витрина: `index.html`.
- Текущ публичен набор: `catalog-snapshot.js` — **5 фиктивни автомобила, 5 фиктивни части, 3 тестови снимки**.
- Изображения: публични миниатюри от Google Drive; само обявени за публично видими файлове.
- **Важно:** данните в `catalog-snapshot.js` са статично публикувано копие. Промени в Google Sheets **не се появяват автоматично** в този тест. Публикуващата синхронизация от административния панел предстои да бъде разработена и тествана.
- Промените по този сайт не засягат оригиналния работещ Google Apps Script каталог.
- Забранено: реално получени суми, финансови операции, имейли на администратори, вътрешни бележки и всякакви тайни.

Състояние GATE-02: динамичната заявка към публичния Apps Script API се провали в Google Sites и GitHub Pages при реален тест от телефон; заменена е с **локален публичен snapshot за изолиран тест**. Не обявявай автоматично обновяване или продукционна готовност преди реален тест на публикуващия механизъм.

Проверка: отваряне на телефон без Инкогнито, 5 автомобила, търсене по „фар“, филтри, 3 снимки и корица, липса на Google Apps Script лента.
